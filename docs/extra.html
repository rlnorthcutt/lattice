Spacing Scale

A 6-step scale (0–5) derived from --lat-space (default 1rem). Available for padding, margin, and gap in all directions using logical CSS properties.

Unequal Column Spans

Put .span-N on items inside .grid for unequal column widths. The grid is 12 tracks wide by default.

Responsive spans — full-width on mobile, split at md

Variable span

Use .span-var with a CSS custom property for dynamic widths:

<div class="span-var" style="--lat-span: 5">5 tracks</div>

Display & Responsive Visibility

All display classes carry !important. Responsive variants apply at their breakpoint and above, so .sm-d-block can reveal something hidden with .d-none.

Base display classes

ClassEffect
.d-noneRemoves from layout
.d-blockdisplay: block
.d-flexdisplay: flex
.d-griddisplay: grid

Responsive prefix: sm-, md-, lg-, xl-, xxl-. E.g. .d-none.md-d-flex hides on mobile, shows as flex on md+.

Hide on mobile, show at md

<nav class="d-none md-d-flex">Desktop nav</nav>
<button class="md-d-none">☰ Mobile menu</button>

Accessibility

Screen-reader only text

Both .sr-only and .visually-hidden hide content visually while keeping it available to screen readers.

<button>
  <svg aria-hidden="true">…</svg>
  <span class="sr-only">Close dialog</span>
</button>

The text below is present in the DOM but visually invisible:

This text is only visible to screen readers.

(Nothing visible above — that's correct.)

Focusable skip links

Combine with .sr-only-focusable (or .visually-hidden-focusable) to create skip links that appear only on keyboard focus:

<a class="sr-only sr-only-focusable" href="#content">Skip to content</a>

Tab to the top of this page to see the skip link appear.

Pointer events

.pe-none disables click/touch interaction. .pe-auto restores it.
