Extra API

Optional helpers for spacing, display, flex, unequal spans, positioning, and accessibility. Load after Core.

Installation

Extra requires Core. Load them in order, or use the full bundle.

<!-- Core (required) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.min.css">
<!-- Extra (optional) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.extra.min.css">

<!-- Or the full bundle -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.full.min.css">

Spacing Scale

A 6-step scale (0–5) built on --lat-space (default: 1rem). Available for padding, margin, and gap.

Display & Visibility

All display classes carry !important for reliable overrides. Responsive versions work at their breakpoint and above.

Classes

ClassProperty
.d-nonedisplay: none
.d-blockdisplay: block
.d-flexdisplay: flex
.d-griddisplay: grid

Responsive prefix: sm-, md-, lg-, xl-, xxl-. Example: .md-d-none, .lg-d-flex.

<!-- Hide on mobile, show as flex on md+ -->
<nav class="d-none md-d-flex">…</nav>

A11y

ClassEffect
.sr-only, .visually-hiddenVisually hidden; readable by screen readers.
.sr-only-focusableSame as above, but revealed on focus (skip links).

Unequal Column Spans

Put .span-* on items inside .grid to create non-uniform layouts. The grid is 12 tracks wide by default.

<div class="grid gap-3">
  <aside class="span-4">Sidebar (4/12)</aside>
  <main class="span-8">Content (8/12)</main>
</div>

<!-- Responsive: full-width on mobile, split at md -->
<div class="grid gap-3">
  <aside class="md-span-3">Sidebar</aside>
  <main class="md-span-9">Content</main>
</div>

Span classes

Available from .span-1 to .span-12, plus responsive variants with sm-, md-, lg-, xl-, and xxl- prefixes.

Use .span-var with a custom property: <div class="span-var" style="--lat-span:5">.
