Two layers

Lattice is split into two files so you only ship what you need. Pair with Ivy for classless HTML defaults.

Core — lattice.css

The 12-column page shell and component grids. Everything you need for reliable, responsive layout.

  • Master page grid (.lattice)
  • Full-bleed and centered sections
  • 12-track component grid (.grid)
  • Equal-column helpers (.grid.col-N)
  • Responsive breakpoints (sm → xxl)
  • Minimal display and visibility utilities
View core demo →

Extra — lattice.extra.css

Optional helpers for spacing, unequal layouts, flex, positioning, and accessibility.

  • Spacing scale (padding, margin, gap)
  • Responsive display toggles
  • Unequal column spans (.span-N)
  • Flex direction, alignment, order
  • Positioning, overflow, z-index
  • Screen-reader utilities
View extra demo →

Installation

Option 1 — Core only

Just the page grid and equal-column helpers. Great for structured layouts without spacing utilities.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.min.css">

Option 2 — Core + Extra

Add spacing, spans, flex helpers, and positioning utilities.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.extra.min.css">

Option 3 — Full bundle

Core + Extra in one file. Simplest option for most projects.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.full.min.css">

Option 4 — With Ivy (recommended)

Load Ivy first for classless HTML defaults, then Lattice for layout control.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/ivy/dist/ivy.full.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.full.min.css">

Quick start

Add .lattice to your page shell. Direct children default to centered (container) width. Add .full-width for edge-to-edge sections.

<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">

<body class="lattice">
  <header class="full-width">…</header>  <!-- bleeds to viewport edges -->

  <main class="container">
    <!-- Equal columns: stack → 3 cols at md+ -->
    <div class="grid col-1 md-col-3 gap-3">
      <article>A</article>
      <article>B</article>
      <article>C</article>
    </div>

    <!-- Unequal columns (requires Extra) -->
    <div class="grid gap-3">
      <aside class="span md-span-4">Sidebar</aside>
      <section class="span md-span-8">Content</section>
    </div>
  </main>

  <footer class="full-width">…</footer>
</body>

Customization

Lattice is driven by CSS custom properties. Override any token in your own stylesheet.

:root {
  --lat-container-width: 1200px;  /* max content width (default: 1024px) */
  --lat-space: 1.125rem;          /* spacing rhythm base (default: 1rem) */
  --lat-gap-x: 1.5rem;            /* horizontal grid gap */
  --lat-gap-y: 1.5rem;            /* vertical grid gap */
}
Safe-area insets

Lattice uses env(safe-area-inset-left/right) in the master grid gutters for notched devices. Include viewport-fit=cover in your viewport meta to activate this.

Token reference

All CSS custom properties defined by Lattice. Override any of them in your own unlayered stylesheet.

Browser support

Lattice uses modern CSS features. All are baseline-supported in every current browser (Chrome, Firefox, Safari, Edge).

FeatureUsed for
grid-template-columnsThe master page grid and .grid component grid
env(safe-area-inset-*)Fluid outer gutters that respect notched devices
Logical propertiespadding-inline, margin-inline, and friends for the spacing scale
color-mix()The translucent, blurred background on .sticky
backdrop-filterBlur behind .sticky elements, including this header
aspect-ratio.aspect-square / .aspect-video
position: stickySticky headers and on-page navigation
