Core API

Page shell, component grids, and the minimal utility set bundled with every Lattice install.

Installation

Core is the only required file. Extra is optional.

<!-- Core only -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.min.css">

<!-- Or the full bundle (Core + Extra) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rlnorthcutt/lattice/dist/lattice.full.min.css">
Self-host 
<link rel="stylesheet" href="/css/lattice.css">
<!-- optional -->
<link rel="stylesheet" href="/css/lattice.extra.css">

CSS Custom Properties

Override these in your own stylesheet to adjust the grid and spacing rhythm.

:root {
  --lat-container-width: 1024px;  /* max content width */
  --lat-col-count: 11;            /* 1 + 11 = 12 content columns */
  --lat-space: 1rem;              /* spacing rhythm base */
  --lat-gap-x: 1rem;              /* horizontal grid gap */
  --lat-gap-y: 1rem;              /* vertical grid gap */
}

For safe-area inset support on notched devices (iOS), include viewport-fit=cover in your viewport meta:

<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">

Page Shell

Add .lattice to the page shell (typically <body>). Direct children default to contained width. Use .full-width to bleed edge-to-edge.

Classes

ClassEffect
.latticeActivates the 12-column page grid with fluid outer gutters.
.containerCenters content at --lat-container-width. Default for all direct children.
.full-widthSpans the full viewport, edge-to-edge (full bleed).
 
<body class="lattice">
  <header class="full-width">…</header>  <!-- bleeds to edges -->
  <main class="container">…</main>       <!-- centered, max-width -->
  <footer>…</footer>                     <!-- defaults to container -->
</body>

Component Grids

Use .grid for any component-level layout. Set the column count on the container; children auto-place into equal tracks.

Equal-column classes (on the container)

ClassColumnsNotes
.grid12 equal tracksDefault. No column class needed for 12-col layouts.
.grid.col-11Stacks all items (useful as a mobile base).
.grid.col-22
.grid.col-33
.grid.col-44

Responsive prefixes

Prefix any column class to apply it at that breakpoint and above. No prefix = all sizes.

PrefixMin-widthExample
noneall sizescol-3
sm-40 rem (640 px)sm-col-2
md-48 rem (768 px)md-col-3
lg-64 rem (1024 px)lg-col-4
xl-80 rem (1280 px)xl-col-4
xxl-96 rem (1536 px)xxl-col-6
 
<!-- Stack on mobile; 3 equal columns at md and above -->
<div class="grid md-col-3 gap-3">
  <article>A</article>
  <article>B</article>
  <article>C</article>
</div>

<!-- Explicit 2-col on small, 4-col on large -->
<div class="grid sm-col-2 lg-col-4">
  <div>…</div>
  <div>…</div>
  <div>…</div>
  <div>…</div>
</div>

For unequal columns (e.g. 3/9, 4/8), use .span-* on items—see Extra Docs.
