Core Demo

Every layout feature below is provided by lattice.css alone. No Extra required — just the page grid, component grids, and a handful of utilities.

Page Shell

Add .lattice to your page shell element (usually <body>). It creates a 12-column master grid with fluid outer gutters that include safe-area insets on notched devices.

Direct children default to container width. Add .full-width to bleed an element edge-to-edge.

<body class="lattice">
  <header class="full-width">
    <!-- spans the full viewport width -->
  </header>

  <main class="container">
    <!-- centered at --lat-container-width (default: 1024px) -->
  </main>

  <footer>
    <!-- no class needed — defaults to container -->
  </footer>
</body>

Component Grids

Responsive Columns

Prefix any column class to apply it at that breakpoint and above. No prefix = all screen sizes (stacked). The grid is mobile-first — stack by default, then apply columns as the screen grows.

PrefixMin-widthEquivalent
noneall sizes.col-3
sm-40 rem (640 px).sm-col-2
md-48 rem (768 px).md-col-3
lg-64 rem (1024 px).lg-col-4
xl-80 rem (1280 px).xl-col-4
xxl-96 rem (1536 px).xxl-col-6

Stack → 1 col at xs → 2 cols at sm → 3 cols at lg

<div class="grid col-1 sm-col-2 lg-col-3 gap-2">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>

Custom Properties

Override these tokens in your own stylesheet to adjust the layout system.

TokenDefaultControls
--lat-container-width1024pxMax content width for .container
--lat-col-count11Column count minus one (1 + 11 = 12 tracks)
--lat-space1remRhythm base; Extra derives all spacing tokens from this
--lat-gap-x1remHorizontal gap in .grid
--lat-gap-y1remVertical gap in .grid
 
/* Example: wider container, tighter grid gaps */
:root {
  --lat-container-width: 1200px;
  --lat-gap-x: 0.75rem;
  --lat-gap-y: 0.75rem;
}
